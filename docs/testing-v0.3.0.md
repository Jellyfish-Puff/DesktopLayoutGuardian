# v0.3.0 实机测试清单

本清单按风险从低到高排列。测试版兼容 v0.2.0 已保存的三套方案。

## 1. 后台与单实例

1. 启动程序，确认主界面可以正常读取当前显示环境。
2. 关闭主窗口，确认程序隐藏到系统托盘。
3. 再次双击程序，确认原窗口被唤醒且没有出现第二个托盘图标。
4. 在托盘菜单中执行“立即重新检测”。

## 2. 现有方案兼容

1. 在当前显示环境确认界面能找到 v0.2.0 保存的方案。
2. 点击“恢复已保存布局”，确认图标位置正常。
3. 确认“撤销最近恢复”按钮变为可用。
4. 点击撤销，确认桌面回到刚才恢复前的位置。

## 3. 自动恢复与防抖

1. 保持程序在托盘运行。
2. 依次切换笔记本内屏、ROG 外接显示器和 UU 超级屏。
3. 每次切换后等待约 5 秒，确认程序只恢复一次对应布局。
4. 改变 UU 超级屏分辨率，确认未保存的新分辨率不会移动图标。
5. 切回已经保存的 UU 分辨率，确认原布局恢复。

## 4. 设置

1. 开启“恢复成功时显示通知”，切换一次屏幕并确认通知出现。
2. 关闭该设置，确认成功恢复保持安静；恢复失败仍会提醒。
3. 开启“登录 Windows 后自动运行”，在任务管理器的启动应用中确认条目存在。
4. 测试完成后可按个人偏好保留或关闭开机启动。

## 5. 退出

必须通过托盘菜单的“退出”真正结束程序；关闭窗口只会隐藏到托盘。
